# Mac版の初回起動

[English](mac-first-start.en.md)

[A2ACraft の公式リリース](https://github.com/thinksyncs/a2acraft/releases/tag/v0.4.27-tauri)で配布している Mac 用 ZIP は **Tauri 版 0.4.27** です。地図と会話の操作は Electron 版と共通です。保存先は版ごとに異なり、過去の会話や下書きを引き継ぐため、保存フォルダの名前には旧名の `chatui` や `chat-ui` が残っています。

0.4.25以降は、初回のConnect画面か「設定 → 言語」で **English** と **日本語** を選べます。選択は次回の起動にも引き継がれます。会話や下書き、取り込んだ履歴は元の言語で表示します。

## アプリを入れる

1. Appleメニューの「このMacについて」で、お使いのMacを確認します。このMac版はApple Mシリーズの `arm64` が対象です。Intel Macは文書取り込み用部品が未対応のため、配布対象に含めません。
2. リリースに添付されている `A2ACraft-0.4.27-Tauri-mac-arm64.zip` をダウンロードします。Finder で ZIP をダブルクリックし、展開された `A2ACraft.app` を「アプリケーション」へドラッグします。
3. コピーしたアプリを開きます。利用する側でNode.jsやHomebrewを用意する必要はありません。

Mac版の通常配布にはDeveloper ID署名とAppleの公証が必要です。macOSが検証エラーを表示した場合は、ZIPのSHA-256をリリース情報の値と照合し、[Appleの案内](https://support.apple.com/ja-jp/102445)を確認してください。

## 画面の読み取りを支援する

Mac上部の「表示 → 画面の読み取りに対応」で読み上げやキーボード操作の補助を有効にできます。設定は次の起動にも引き継がれます。Tauri版では、会話中にF6で履歴と入力欄の間を移動できます。

会話本文には、Tabキーで移動できる「会話名の会話履歴」という領域があります。大量の履歴を取り込んでも、全文を自動的に読み上げる設定にはしていません。

## まず街を試す

「接続せずに開く」からアプリを開き、メニューの「村のデモを見る」を選ぶと、サンプルの街を歩き、村人と話し、地図へ戻る操作を試せます。

- 地図の地面をクリックすると、パーティがその場所へ歩きます。W・A・S・Dでも移動できます。
- ドラッグやスクロールで周囲を見回し、「全体へ」で大陸を表示します。
- 村人を選ぶと相手のそばへ歩き、互いに向き合います。「話す」で地図上にその人のチャットが開きます。「会話を広げる」で通常の会話画面に切り替えられます。
- 仲間を連れて村人の近くにいると、仲間が声をかけ、村人が自分の会話の続きを話します。「この辺りの会話」の「仲間の立ち話」でオン・オフを切り替えられます。
- 「この辺りの会話」には、近くの会話名と直近の依頼が表示されます。選ぶと、その村人へ歩きます。名簿から遠くの村人を探すこともできます。
- 移動中はパーティにカメラが追従し、行き先と残り時間を表示します。「全体へ」で見回しても歩行は続き、「歩行に追従」で戻れます。一時停止中は残り時間も止まります。
- 村人は家の周辺を散策し、話しかけると立ち止まります。
- 会話の「街へ戻る」で、相手とパーティのいる地図へ戻ります。
- 右上のリーダー目線と2D地図は、同じ位置の人物・地形を表示します。目線の小窓は閉じて再表示できます。

デモの返事はサンプルです。実際にAIへ依頼する場合は、アプリを終了して通常の方法で開き直します。

### サンプルの歩行と会話を録画する

公開ZIPには「村の散策と会話を録画.command」も入っています。録画する場合はFinderでこのファイルを開きます。アプリがサンプル専用の新しい村を開き、村人まで歩いて地図上で質問を送り、仲間の立ち話を待ちます。撮影中は村のウィンドウを表示しておいてください。

完了するとターミナルに再生用ファイルの場所が表示されます。「村の散策と会話.html」を開くと、歩行・チャット・立ち話の各場面を選べます。起動時にエラーが出た場合は、同じ録画先の `startup.txt` でMacが起動を受け付けたか確認できます。アプリ内の撮影結果は `sample/recording/result.json` に残ります。

## 地図を見回す

建物・人物・木・岩山は、俯瞰地図とリーダー目線で同じ立体モデルを使います。
トラックパッドの2本指スクロールで地図を動かし、ピンチで指している場所を拡大・縮小します。
「＋」「−」でも拡大・縮小でき、「全体へ」で島全体に戻ります。
人物の服装と向き、建物の屋根や壁は拡大すると詳しく見えます。

## 仲間と村人に話しかける

酒場で仲間と役割を選んで保存し、村の地図から村人に話しかけます。会話画面の「同行」で、今回連れている仲間を確認できます。「仲間を変える」から酒場へ戻り、編成を変えてもう一度訪ねられます。

質問を送ると、選んだ仲間の役割と、各会話の直近のユーザー・アシスタント発言を参考情報としてCodexに渡します。抜粋は1人あたり最大2,000文字、全員で最大8,000文字です。添付ファイルやツールの実行記録は含めません。村人は質問に関係する仲間の知識を使い、提案の優先順位や具体例を調整します。仲間自身が新しく発言・作業する機能ではありません。

通常のチャットには、この同行者情報を追加しません。プロジェクトの地図は現在、一人で訪ねる扱いです。酒場の仲間を自動的に同行させません。

## 発見を相手に渡す

冒険画面の工房には、次の2つのボタンがあります。

- **発見をコピー**：受け取った最新の冒険の成果から、短いコードをコピーします。普段使っているメッセージなどで相手に渡してください。クリップボードを使えない場合は、表示されたコードを選んでコピーできます。
- **相手の発見を取り込む**：届いたコードを1つ貼り付けて取り込みます。初めて受け取った発見が保存されると、工房に明かりが灯ります。

コードに含むのは、ハッシュ化したクエストID・発見ID・種類だけです。依頼文、会話本文、エージェントの出力、名前、ファイルは共有しません。同じコードを再度取り込んでも件数や進捗は増えず、アプリを再起動しても重複を判定します。工房の発見数は、冒険のクエスト完了や地方の解放とは別の記録です。

今はコードを手渡しする方式です。共有フォルダやGoogle Driveとの自動同期、アプリ内のGoogleログインは使いません。デモでは公開のサンプル発見をコピーして、この受け渡しを試せます。

## 自分の仕事を始める

実際の会話には、Codexを利用できるChatGPTアカウントが必要です。公式Codex CLIはアプリに同梱しており、別途インストールは不要です。A2ACraft専用のログインとして扱い、すでに使っているCodexアプリの認証情報をコピーしません。

1. 接続設定で「Codexに接続」を選びます。同梱のCodexが起動します。保存済みのログインがあれば、そのまま接続します。
2. 初回は、アプリが示す公式ログイン画面で自分のChatGPTアカウントを使って認証します。認証をやり直す場合は「ログインし直す」を選びます。
3. 「会話・作業の接続を確認」で、会話とファイル作業それぞれの準備を確認します。この操作はAIへ依頼を送らず、会話本文も送信しません。「接続準備OK」は準備の確認結果です。
4. 新しい会話を開き、「村の鍛冶屋として一言あいさつして」と送ります。会話に Codex の返事が表示されることを確認します。
5. 同じ会話の入力欄で「＋」を開き、「実行範囲」を「相談（読み取りのみ）」から「作業（専用フォルダ内）」に切り替えます。
6. 「この会話の専用フォルダに `hello.txt` を作り、`Hello from A2ACraft` と1行書いてください。保存したファイルの絶対パスを教えてください」と送ります。
7. Finder で ⌘⇧G を押し、返事にある保存先のフォルダを開きます。`hello.txt` を開いて依頼した1行を確認します。保存先は作業フォルダの `chats/<会話ID>/` です。

この接続にGitHub CLIの認証は不要です。GitHubや他サービスとの実際の連携は、別途その機能の設定が必要です。

接続後の「接続状態を更新」は、ログイン状態と利用枠を読み直す操作です。Macの管理設定を変更した場合は、A2ACraftを終了して開き直してから「会話・作業の接続を確認」を実行してください。更新ボタンだけでは管理設定を読み直しません。

作業用のフォルダを変える場合は、設定で専用フォルダを選ぶか、「専用フォルダのパス」に場所を入力し、「作業場所を保存」を押してアプリを再起動します。管理されたMacで既定の作業場所が拒否される場合も、すでに利用を許可された専用フォルダを指定できます。会話データとログイン情報は元の場所に保持されます。端末の保護設定を緩める必要はありません。

## 取り込んだ履歴から続ける

会話本文の見出し、箇条書き、表、コードなどはMarkdownとして表示します。デスクトップの会話画面は、上部1段にグループのタブと操作ボタンをまとめています。未接続の場合は「未接続」ボタンから接続設定を開けます。保存失敗や実行エラーの通知は表示します。会話画面上部の「1×1」「1×2」「2×2」で表示数を切り替えます。作成済みの会話グループを選ぶと、その会話を同時に表示できます。各枠は個別にスクロールでき、選んだ枠が下の入力欄の送信先になります。

地図の村人は依頼や返答の本文を表示します。「詳しく」では、その会話の最新の依頼と返答を読めます。

「保存した履歴を開く」で、取り込んだ会話を選びます。会話を開くだけではAIへ送信しません。接続確認後、入力欄から依頼を送ると、取り込んだ会話を引き継ぐための内容を準備します。長い会話は全文を会話専用フォルダに保持し、直近の抜粋と全文への参照を使います。

追加で取り込む場合は「Codex appから履歴を取り込む」→「Codexの履歴ファイルを取り込む」からJSONLファイルを選びます。移すのはユーザーとアシスタントの会話本文です。元の履歴は保持し、認証情報・設定・画像原本・ツール実行記録は取り込みません。

## 保存と終了

会話はMac上のアプリ専用領域に保存されます。下書きは会話ごとに保存され、アプリの終了時にも保存を確認します。終了前の保存に失敗したら「戻る」「保存を再試行」「保存せずに終了」から選べます。「表示 → 画面を再読み込み」（⌘R）でも、下書きと地図の保存を確認してから画面を更新します。

アプリ本体の置き換えと、保存済みデータの削除は別です。更新時にApplication Support内のデータを削除しないでください。クラウド同期や端末間の自動移行は行いません。

「接続せずに開く」で使っていた場合、再読み込みや再起動のあとにConnect画面へ戻ります。もう一度「接続せずに開く」を選ぶと、保存した下書きと会話表示を開けます。Connect画面が出ること自体は、下書きの消失を意味しません。

## 起動や接続がうまくいかないとき

| 状況 | 操作 |
| --- | --- |
| 新版を開いても旧版が出る | 起動中のアプリを終了し、保存確認が出た場合は対応します。Finder の「アプリケーション」で対象の A2ACraft を選び、⌘I の「情報を見る」でバージョンを確認してから開きます。 |
| ウィンドウが見えない | Mac 上部の「ウィンドウ → 表示を復帰」を選びます。「ウィンドウ → 表示の診断」で表示・読み込み・応答状態を確認できます。 |
| 画面が更新されない | 「表示 → 画面を再読み込み」を選びます。下書きと地図の保存を確認してから画面を読み込み、保存に失敗した場合は現在の画面を保持します。 |
| 同梱のCodexが見つからない | アプリを配布元の完全なZIP／DMGから入れ直します。独自のCLIを使う場合だけ、接続設定で実行ファイルを選び、再起動します。 |
| ログイン待ち・接続失敗 | 接続設定の「Codexに接続」、接続済みなら「接続状態を更新」を使います。認証のやり直しが必要な場合に「ログインし直す」を選びます。 |
| 接続確認で実行範囲が一致しない | Macの管理者に確認結果を共有します。SSH・Protonの保護を維持し、会話は読み取り専用、作業は会話専用フォルダに制限する設定が必要です。設定変更後はA2ACraftを終了して開き直し、接続を確認します。 |
| 利用枠のため送信できない | 「Codex 利用状況」を確認します。残量がアプリの停止ライン以下の場合は、枠の回復後に更新して再送信します。接続の準備確認は実行できます。 |
| 保存できない | Macの空き容量とアプリの保存先を確認し、画面を閉じる前に保存を再試行します。 |
| バックエンドが異常終了した | 復帰の案内で「再起動」を選びます。保存済みの会話を開き、中断した依頼の状態を確認してから続けてください。 |

同梱ソフトウェアの通知は、Tauri 版ではアプリ本体の `Contents/Resources/backend/licenses/`、Electron 版では `Contents/Resources/licenses/` にあります。

同じ A2ACraft リポジトリから両版をビルドできます。[Tauri 版のビルド手順](tauri.md) · [Electron 版のビルド手順](electron.md) · [Electron 版の検証状況](preview-status.md)
