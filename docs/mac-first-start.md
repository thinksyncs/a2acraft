# Mac版の初回起動

製品名は **A2ACraft** です。既存データを引き継ぐため、内部のアプリIDと保存先の名前は維持しています。

この手順は、ビルドされたMac用アプリを受け取った方向けです。現時点の標準ビルドは**開発者署名・公証前の確認用パッケージ**です。一般配布版の検証完了や、Appleによる公証を示すものではありません。

## アプリを入れる

1. Appleメニューの「このMacについて」で、お使いのMacを確認します。今回の確認版はApple Mシリーズの `arm64` が対象です。Intel Macは文書取り込み用部品が未対応のため、配布対象に含めません。
2. DMGを開き、`A2ACraft.app` を「アプリケーション」へコピーします。ZIPの場合は展開してからコピーします。
3. コピーしたアプリを開きます。利用する側でNode.jsやHomebrewを用意する必要はありません。

開発者署名・公証前のアプリについてmacOSが警告する場合があります。配布元と内容を確認できた確認用ビルドに限り、macOSの「システム設定 → プライバシーとセキュリティ」に表示される個別の起動操作を使います。通常配布に進む前に、配布者が署名・公証を済ませる必要があります。

## まず街を試す

「接続せずに開く」からアプリを開き、メニューの「村のデモを見る」を選ぶと、サンプルの街を歩き、村人と話し、地図へ戻る操作を試せます。

- 地図の地面をクリックすると、パーティがその場所へ歩きます。W・A・S・Dでも移動できます。
- ドラッグやスクロールで周囲を見回し、「全体へ」で大陸を表示します。
- 村人を選ぶと相手のそばへ歩き、互いに向き合います。「話す」で会話を開きます。
- 会話の「街へ戻る」で、相手とパーティのいる地図へ戻ります。
- 右上のリーダー目線と2D地図は、同じ位置の人物・地形を表示します。目線の小窓は閉じて再表示できます。

デモの返事はサンプルです。実際にAIへ依頼する場合は、アプリを終了して通常の方法で開き直します。

## 自分の仕事を始める

実際の会話には、Codexを利用できるChatGPTアカウントが必要です。公式Codex CLIはアプリに同梱しており、別途インストールは不要です。A2ACraft専用のログインとして扱い、すでに使っているCodexアプリの認証情報をコピーしません。

1. アプリを開いて「Connect」を選びます。同梱のCodexが起動します。
2. アプリが示す公式ログイン画面で、自分のChatGPTアカウントを使って認証します。
3. 最初の会話を作って依頼を送ります。既存の会話は履歴から開けます。
4. 街で会話や作業を選び、必要なときに相談へ移動します。新しい仕事や連携先の設定は、対応する画面から追加します。

この接続にGitHub CLIの認証は不要です。GitHubや他サービスとの実際の連携は、別途その機能の設定が必要です。

作業用のフォルダを変える場合は、設定で専用フォルダを選ぶか、「専用フォルダのパス」に場所を入力し、「作業場所を保存」を押してアプリを再起動します。管理されたMacで既定の作業場所が拒否される場合も、すでに利用を許可された専用フォルダを指定できます。会話データとログイン情報は元の場所に保持されます。端末の保護設定を緩める必要はありません。

## 保存と終了

会話はMac上のアプリ専用領域に保存されます。下書きは会話ごとに保存され、アプリの終了時にも保存を確認します。保存に失敗した場合は「戻る」または「保存を再試行」を選べます。「保存せずに終了」を選ぶと、未保存の変更は失われます。

アプリ本体の置き換えと、保存済みデータの削除は別です。更新時にApplication Support内のデータを削除しないでください。クラウド同期や端末間の自動移行は行いません。

## 起動や接続がうまくいかないとき

| 状況 | 操作 |
| --- | --- |
| 同梱のCodexが見つからない | アプリを配布元の完全なZIP／DMGから入れ直します。独自のCLIを使う場合だけ、接続設定で実行ファイルを選び、再起動します。 |
| ログイン待ち・接続失敗 | 接続画面からログインを開き直すか、「再接続」を使います。 |
| 保存できない | Macの空き容量とアプリの保存先を確認し、画面を閉じる前に保存を再試行します。 |
| アプリ内の接続が終了した | 表示されたエラーを記録してアプリを開き直します。 |

同梱ソフトウェアの通知は、アプリ本体の `Contents/Resources/licenses/` にあります。

ビルド方法と検証条件は [Electron版の説明](electron.md) を参照してください。
