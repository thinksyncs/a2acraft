# 村人に会ったときの表示

村人と向き合うと、その人の名前に続いて「何の話か」「どこまで話したか」が読めます。村の地図と開発の全体マップで同じ順序を使います。

- **話題**には会話名を使います。「Codexから移行」のような仮の名前や依頼と同じ文は省きます。
- **最新の依頼・最新の返答**には、保存された会話から、直近の依頼とその後の返答を抜粋します。返答待ちならその状態を表示します。「続けて」のように前の話を指す依頼には、直前の具体的な依頼を添えます。
- **確認事項・進捗**は、担当工程に実際の報告があるときに表示します。以前の発言を再訪時の報告として紹介する場合は「以前の依頼」「以前の返答」と明記します。
- 吹き出しでは依頼・返答をそれぞれ最大180文字程度に収め、長い文の末尾に「…」を付けます。**詳しく**で今回の依頼と返答の全文を開き、**話す**で同じ会話を続けられます。開発の全体マップでは吹き出し内の「依頼と最新の返答を読む」から全文を開けます。

抜粋は端末上で表示時に選びます。Codexの選択ページや実行環境の情報だけが入った項目は飛ばし、同じメッセージに利用者の発言があればその部分を表示します。Markdownのコードブロック中に引用されたタグはコード例として表示します。元の会話はそのまま保持します。

### 地図でチャットを続ける

「話す」でその村人の会話履歴と入力欄を地図の横に開きます。幅の狭い画面では地図の下に開きます。俯瞰とリーダー目線で同じ出会いを見ながら、通常の会話と同じ送信先・下書きを使います。「会話を広げる」で元の会話レイアウトに移り、「街へ戻る」で散策を再開します。

### 仲間から声をかける

隊に仲間がいると、近くで出会った村人に仲間が話しかけます。質問には話題を、返事にはその村人の履歴から依頼か返答を短く引用し、二人の名前を添えます。立ち話は端末上で表示し、Codexの利用枠を使いません。自分で村人と話すときや目的地へ歩いている間は休み、同じ相手との連続表示も避けます。「この辺りの会話」からいつでも切り替えられます。
